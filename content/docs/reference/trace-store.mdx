# Trace Store

Trace stores persist ordered event streams for runs. They are the source of truth
for replay, audit, exported traces, and run inspection.

## Trace records

Trace records include run identity, sequence number, event payload, record time,
and integrity metadata where enabled.

## Integrity Chain

Integrity chains make missing, reordered, or corrupted trace segments detectable.

## Trace Export Tool

Use `splendorctl trace export --db <path> --run <id>` to emit JSON Lines for a
run. Each line is a serialized `TraceRecord`.

## Failure behavior

Trace persistence failures are runtime-significant. If a required trace event
cannot be written before a side effect, Splendor must fail closed rather than run
the adapter without evidence.
