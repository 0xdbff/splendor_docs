The Splendor reference summarizes public runtime contracts for local execution,
SDKs, daemon clients, examples, trace/replay tooling, and stable primitive
schemas. It intentionally avoids private crate internals and test-only details.

Use this section when you need to understand what a Splendor run records,
enforces, or exposes through public APIs.

## Compatibility boundaries

Stable public contracts preserve:

- distinct identity fields;
- gateway-mediated side effects;
- fail-closed verifier behavior;
- explicit state commits;
- append-only trace events;
- replay side-effect suppression by default;
- SDK and client behavior that does not bypass runtime enforcement.
